# قوة الحوض — تطبيق تمارين كيجل

**من تطوير: حامد الدهاش**

تطبيق أندرويد عربي لتمارين قاع الحوض: برنامج 180 يومًا، مدرب موقّت، اهتزاز توجيهي، وإشعارات في موعد كل تمرين.

- الواجهة كاملة في `www/index.html`.
- الأيقونة مأخوذة من تصميم Canva (`assets/`).
- كل دفع إلى `main` يبني APK تلقائيًا وينشره في Releases.

**تحميل آخر إصدار:** `releases/latest/download/kegel.apk`
